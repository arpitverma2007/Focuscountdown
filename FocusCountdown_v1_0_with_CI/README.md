# Focus Countdown v1.0

A calm Android countdown + progress + personal journey starter.

## Included
- Multiple countdown goals
- Exact date and time picker
- Main countdown
- Days + HH:MM:SS
- Countdown completion percentage
- Home screen widget via Jetpack Glance
- Daily journal
- Study hours and mood
- Achievement field
- Local persistence using SharedPreferences/JSON
- Progress dashboard
- Offline-first design
- Calm cream / forest green / terracotta visual direction

## Open in Android Studio
1. Extract the ZIP.
2. Open the `FocusCountdown_v1_0` folder in Android Studio.
3. Let Gradle sync.
4. Connect an Android phone with USB debugging or start an emulator.
5. Press Run.

## Add the widget
After installing:
1. Long-press an empty area of the Android home screen.
2. Tap Widgets.
3. Find Focus Countdown.
4. Drag the widget to the home screen.

## Notes
This is a functional v1.0 starter project. The next production pass can add Room migrations, notification scheduling, true widget live-refresh strategies, calendar heatmap, editing/deleting goals and entries, dark mode, backup/export, and richer animations.
